# Entre Nós — Hello World

Pequeno projeto Next.js para testar a publicação na Vercel.

## Executar localmente

Requer Node.js 20 ou superior.

```bash
npm install
npm run dev
```

Abrir http://localhost:3000

## Publicar

1. Criar um repositório privado no GitHub.
2. Descompactar o ZIP e carregar **o conteúdo da pasta** para a raiz do repositório (incluindo a pasta `app`).
3. Na Vercel, selecionar Add New → Project e importar o repositório.
4. Confirmar Next.js e clicar em Deploy.

Este projeto é apenas um teste, sem contas, pagamentos ou base de dados.
